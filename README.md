# Tally Helper — Codespaces থেকে Native Android App বানানোর নিয়ম

এই ফোল্ডারটা একটা **Capacitor প্রজেক্ট** — আপনার Tally Helper অ্যাপকে (যেটা `www/` ফোল্ডারে আছে) একটা আসল নেটিভ Android অ্যাপে (APK) রূপান্তর করে। GitHub Codespaces-এ পুরো প্রসেসটা স্বয়ংক্রিয়ভাবে সেটআপ হয়ে যায় — নিজের কম্পিউটারে Android Studio ইনস্টল করার দরকার নেই।

## ধাপ ১: GitHub রিপোজিটরিতে তুলুন

1. **github.com** এ লগইন করুন, একটা নতুন **রিপোজিটরি** বানান (Public বা Private, যেকোনোটা)
2. রিপোর ভেতরে "Add file → Upload files" চেপে এই পুরো ফোল্ডারের সব ফাইল/সাবফোল্ডার (`.devcontainer`, `www`, `scripts`, `package.json`, `capacitor.config.json`, `.gitignore`) আপলোড করুন
   - ব্রাউজারে সরাসরি ফোল্ডার ড্র্যাগ-ড্রপ করলে সাবফোল্ডার-স্ট্রাকচার ঠিক থাকে
   - Git ব্যবহার করতে জানলে `git init && git add . && git commit -m "init" && git push` দিয়েও করতে পারেন

## ধাপ ২: Codespace খুলুন

1. রিপোর পেজে সবুজ **"Code"** বাটনে চাপুন
2. **"Codespaces"** ট্যাব → **"Create codespace on main"**
3. একটা ব্রাউজার-ভিত্তিক VS Code খুলবে, আর ব্যাকগ্রাউন্ডে স্বয়ংক্রিয়ভাবে সেটআপ শুরু হয়ে যাবে (Java, Android SDK, npm প্যাকেজ ইনস্টল, Android প্রজেক্ট তৈরি)
4. এটা **৩-৭ মিনিট** লাগতে পারে প্রথমবার — নিচে টার্মিনালে progress দেখা যাবে

## ধাপ ৩: APK বিল্ড করুন

সেটআপ শেষ হওয়ার পর:

1. একটা **নতুন টার্মিনাল** খুলুন (Terminal মেনু → New Terminal) — এটা জরুরি, কারণ আগের টার্মিনালে পরিবেশ ভেরিয়েবল আপডেট হয়নি
2. এই কমান্ড চালান:
   ```
   npm run build:android
   ```
3. প্রথমবার Gradle নিজে থেকে অনেক ফাইল ডাউনলোড করবে — **৫-১৫ মিনিট** পর্যন্ত লাগতে পারে, ধৈর্য ধরুন
4. শেষে "BUILD SUCCESSFUL" দেখলে APK তৈরি হয়ে গেছে

## ধাপ ৪: APK ডাউনলোড করুন

1. বাম পাশের ফাইল এক্সপ্লোরারে যান: `android/app/build/outputs/apk/debug/app-debug.apk`
2. ফাইলটার উপর **right-click → Download...**
3. এখন এই APK ফাইলটা WhatsApp/Google Drive/যেকোনো মাধ্যমে সরাসরি শেয়ার করতে পারবেন

যে ফোনে ইনস্টল করবে, প্রথমবার "Install from unknown sources" পারমিশন চাইবে (Play Store থেকে না আসায় স্বাভাবিক) — অনুমতি দিলেই ইনস্টল হয়ে যাবে।

## অ্যাপ আপডেট করলে

`www/index.html` (বা অন্য কোনো ফাইল) বদলালে শুধু ওই ফাইলটা রিপোতে আপডেট করে আবার `npm run build:android` চালালেই নতুন APK তৈরি হয়ে যাবে — পুরো প্রসেস আবার করতে হবে না।

## ক্যামেরা নিয়ে একটা গুরুত্বপূর্ণ কথা

সাধারণ Capacitor প্রজেক্টে ওয়েবের `getUserMedia` (আপনার লাইভ ক্যামেরা/ফ্ল্যাশ ফিচার) নেটিভ অ্যাপে এমনিতে কাজ করে না — তাই `scripts/patch-android.sh` স্বয়ংক্রিয়ভাবে `MainActivity` ফাইলে ক্যামেরা পারমিশন হ্যান্ডলিং কোড বসিয়ে দেয় (সেটআপের সময় নিজে থেকেই চলে)। প্রথমবার অ্যাপ খুললে ফোন ক্যামেরা পারমিশন চাইবে — অনুমতি দিলেই ছবি তোলা/ফ্ল্যাশ কাজ করবে।

## সমস্যা হলে

- **`wget` ফেইল করলে (Android SDK ডাউনলোড):** `.devcontainer/setup.sh` ফাইলে `CMD_TOOLS_ZIP` এর ভার্সন নম্বরটা পুরনো হয়ে থাকতে পারে। https://developer.android.com/studio#command-tools থেকে "Command line tools only" সেকশনের Linux লিংক কপি করে স্ক্রিপ্টে বসিয়ে আবার চালান
- **ক্যামেরা কাজ না করলে:** `android/app/src/main/java/.../MainActivity.java` ফাইলটা ঠিকমতো প্যাচ হয়েছে কিনা দেখুন (স্ক্রিপ্টের আউটপুটে "Patched MainActivity..." লেখা আসার কথা)
- **সিগনেচার-সহ রিলিজ APK লাগলে** (Play Store-এ পাবলিশ করতে চাইলে): সেটার জন্য আলাদা সাইনিং key বানাতে হবে — দরকার হলে জানাবেন, আলাদা করে সাহায্য করব
